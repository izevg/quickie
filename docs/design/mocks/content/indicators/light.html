LiquidGlassWindow

A borderless macOS Tahoe window hierarchy designed to prioritize primary document buffers while exposing system interaction solely on demand.

Overview

In traditional window layouts, titlebars and toolbar accessory views permanently consume screen real estate. The LiquidGlassWindow protocol allows personal web browsers and specialized toolchains to yield 100% of physical pixels to the active frame buffer.
